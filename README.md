# FirstPersonShooter — FPS Alien Drone Survival

A first-person survival shooter built in **Unreal Engine 5.0 EA** where you fight off waves of alien drones.

## About

Survive as long as you can against relentless alien drones in a horrific night-sky environment. Scavenge ammo and health pickups, gear up, and stay alive.

## Features

- FPS gameplay with gun mechanics, ammo, and health systems
- Horrific night sky atmosphere with stars — dark, tense, and terrifying
- Modular building set for level design
- Sound design for immersive survival tension

## Project Structure

```
Content/
├── Assets/
│   ├── Ammo/          # Ammo pickups
│   ├── Characters/    # Player & drone characters
│   ├── Gun/           # Weapon assets
│   ├── Health/        # Health pickups
│   ├── Sounds/        # Audio assets
│   └── Textures/      # Textures & materials
├── Maps/
│   └── FPS_Level      # Main gameplay level
└── ModularBuildingSet/ # Environment building pieces
```

## Getting Started

1. Clone the repo
2. Open `FirstPersonShooter.uproject` with Unreal Engine 5.0 EA
3. Open the `FPS_Level` map and hit Play
